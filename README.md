# TaskMaster Web
Sistema web para gestion de tareas academicas.

## Stack
- Frontend: HTML5 + CSS3 + JavaScript (MVVM)
- Backend: PHP 8 + MySQL (mysqli)
- Deploy: Hostinger

## Instalacion local
1. Copiar en C:/xampp/htdocs/TaskMaster-Web/
2. Importar database/taskmaster_db.sql en phpMyAdmin
3. Abrir http://localhost/TaskMaster-Web/

### Usar servidor Node.js

Si prefieres levantar la app con Node.js en lugar de PHP:

1. `cd TaskMaster-Web`
2. Ejecuta `npm install`
3. Inicia el servidor con `npm start`
4. Abre `http://localhost:3000/`
